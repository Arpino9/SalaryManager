# 給与明細管理(仮)　使い方
ダウンロード後、フォルダ名を「SalaryManager」に変更してVisual Studio上でデバッグ実行し、exeファイルを起動してください。

### 出力
![image](https://user-images.githubusercontent.com/77906739/236664161-e03bda43-6a3d-4642-b9de-e5d0b87e625a.png)

<ul>
<li><b>Excel</b></li>
<p>登録されている全ての明細データを、指定したフォルダにExcel出力します。</p>

<li><b>スプレッドシート</b></li>
<p>登録されている全ての明細データを、指定したGoogleドライブのスプレッドシートに出力します。<br/>
設定手順は以下の通りです。<br/>

1.認証ファイルの取得<br/>
こちらの機能を使う場合は、以下の手順を参考にGoogle DriveとGoogle SheetsのAPIの有効化と、Google Cloud PlatformからJSON型式の秘密鍵(認証ファイル)を取得してください。<br/>
<a href="https://noitalog.tokyo/google-spreadsheet/">https://noitalog.tokyo/google-spreadsheet/</a><br/>
取得した秘密鍵は、以下の場所に配置してください。<br/>
SalaryManager > SalaryManager.Infrastructure > SpreadSheet<br/>

2.テンプレートのコピー<br/>
コピー元のテンプレートを自分のGoogle Driveにコピーしてください。<br/>
<a href="https://docs.google.com/spreadsheets/d/1rW0Ss1STiZ8VoudwMxWkIxOkQl7SY1RnbDp-hRJdAEg/edit?usp=sharing">
https://docs.google.com/spreadsheets/d/1rW0Ss1STiZ8VoudwMxWkIxOkQl7SY1RnbDp-hRJdAEg/edit?usp=sharing</a>

コピーしたシートは規定値(読み取りのみ)で書き込みができないため、共有から書き込みを許可してください。<br/>
![image](https://user-images.githubusercontent.com/77906739/236669848-566cf399-c73a-4351-a04d-8e402715a6d2.png)<br/>

一時的なアクセスの「役割」を「編集者」にすれば外部から書き込みが可能になります。<br/>
変更後、[完了]ボタンを押せばOKです。<br/>
![image](https://user-images.githubusercontent.com/77906739/236669940-df214569-e11d-41ff-88d6-8f5e7626c71f.png)


3.オプションで取得した設定を反映させる<br/>
編集 > オプション > スプレッドシートから取得した認証ファイルとスプレッドシートIDを設定します(シートIDではないので注意)。<br/>

【スプレッドシートIDの確認方法】<br/>
https://docs.google.com/spreadsheets/d/スプレッドシートID/edit#gid=シートID<br/>
</p>
</ul>

## メイン画面(明細入力画面)
![勤怠入力](https://user-images.githubusercontent.com/77906739/227944607-62c5ce50-06e1-465a-972a-b4ae41d8bb12.png)
<ul>
<li><b>所属会社名</b></li>
<p>派遣・出向の場合は雇用元(派遣元)の会社名が表示されます。<br/>
職歴入力画面から自動取得しているため、明細データがない場合や該当する会社名が存在しない場合は表示されません。<br/>
該当する所属会社名がない場合は「<未登録>」と表示されます。</p>
</ul>

<ul>
<li><b>勤務先</b></li>
<p>実際の勤務場所を入力します。派遣契約の場合の派遣先などが該当します。</p>
</ul>

<ul>
<li><b>支給額</b></li>
<p>給与明細の支給額を入力します。<br/>
各項目を入力することで、「支給額計」に合計額が表示されます。<br/>
また、控除額を入力することで支給額から控除額を差し引いた差引支給額が表示されます。<br/>
1年前の明細が登録されている場合、金額部分にカーソルを当てることで画面下に差額が表示されます。</p>
</ul>

<ul>
<li><b>控除額</b></li>
<p>給与明細の控除額を入力します。<br/>
支給額同様に各項目を入力することで、「控除額計」に合計額が表示されます。<br/>
支給額同様に、1年前の明細が登録されている場合は金額部分にカーソルを当てることで画面下に差額が表示されます。</p>
</ul>

<ul>
<li><b>勤務備考</b></li>
<p>給与明細の勤務備考を入力します。</p>
</ul>

<ul>
<li><b>副業など</b></li>
<p>副業などの収入があれば入力します。<br/>
支給額同様に、該当月の1年前との差額があれば画面下に表示されます。<br/>
合計額の表示は正数が青色、負数が赤色です。</p>
</ul>

<ul>
<li><b>月収一覧(画面右)</b></li>
<p>対象年度を対象とする支給額、差引支給額、副業額の合計が表示されます。<br/>
一番下に各項目の合計額が表示されるため、年収の確認にも利用できます。</p>
</ul>

## 経歴入力画面
![スクリーンショット 2023-04-09 110555](https://user-images.githubusercontent.com/77906739/230750533-d27f7d1b-3a56-4ba3-9c39-cd8b2289708f.png)
<ul>
<li><b>経歴一覧(上部のリスト)</b></li>
<p>登録されている経歴が一覧表示されます。</p>
</ul>

<ul>
<li><b>雇用形態</b></li>
<p>雇用形態を選択します</p>
</ul>

<ul>
<li><b>会社名</b></li>
<p>経歴として登録する会社名を入力します。</p>
</ul>

<ul>
<li><b>勤務期間</b></li>
<p>上記の会社に勤めていた期間を「開始日～終了日」の順に指定します。<br/>
ここで指定された期間内の給与明細入力画面に、会社名が表示されます。<br/>
会社名が現在の勤務先である場合は、「就業中」を選択してください。</p>
</ul>

<ul>
<li><b>社員番号</b></li>
<p>社員番号を入力します(省略可能)。</p>
</ul>

<ul>
<li><b>手当</b></li>
<p>会社に備わっている手当を選択します。<br/>
ここで選択された手当のみ、給与明細画面から入力が可能となります。</p>
</ul>

<ul>
<li><b>備考</b></li>
<p>特記事項などを入力できます(省略可能)。</p>
</ul>

<ul>
<li><b>追加</b></li>
<p>入力された経歴データを登録し、一覧に追加します。<br/>
会社名が入力されている場合のみ押下可能です。</p>
</ul>

<ul>
<li><b>更新</b></li>
<p>一覧から選択された経歴データを、入力された値に更新します。</p>
</ul>

<ul>
<li><b>削除</b></li>
<p>一覧から選択された経歴データを削除します。</p>
</ul>
